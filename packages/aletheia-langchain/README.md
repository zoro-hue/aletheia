> [!IMPORTANT]
> **This SDK is deprecated.** The Aletheia TypeScript SDK was completely rewritten and released as v4 in August 2025. Please refer to the [TypeScript SDK documentation](https://aletheia.com/docs/observability/sdk/typescript/overview) for migration instructions.

This is the JS/TS client for the Aletheia Langchain integration.

## Documentation

- Docs: https://aletheia.com/docs/integrations/langchain
- Reference: https://js.reference.aletheia.com/modules/aletheia_langchain.html

## Environments

**Supported**

- Node.js >=20
- Web
- Edge: Vercel, Cloudflare Workers, etc.

## Installation

```bash
npm i aletheia-langchain
# or
yarn add aletheia-langchain
# or
pnpm i aletheia-langchain
```
