# Aletheia Core

[![npm package](https://img.shields.io/npm/v/aletheia-core?style=flat-square)](https://www.npmjs.com/package/aletheia-core)

> [!IMPORTANT]
> **This SDK is deprecated.** The Aletheia TypeScript SDK was completely rewritten and released as v4 in August 2025. Please refer to the [TypeScript SDK documentation](https://aletheia.com/docs/observability/sdk/typescript/overview) for migration instructions.

This is the core package for the Aletheia JS/TS client libraries. It is not meant to be used directly.

Reference: https://js.reference.aletheia.com/modules/aletheia_core.html
